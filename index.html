Guia de tascas · Portugal

Onde se come a sério.

Uma tasca não é um conceito. É uma sala pequena, um quadro com o prato do dia, vinho da casa no copo e a conta no papel. Este guia trata dessas casas — as que ainda cozinham para o bairro, não para o algoritmo.

Como se usa

  1. Pede o prato do dia. É o que a casa comprou de manhã.
  2. O vinho da casa chega. Se não chegar, pede um fino.
  3. O couvert não é obrigatório. «Não, obrigado» resolve.
  4. Horários neste guia são uma indicação. A porta é a fonte.
